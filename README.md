# MicroBee\_MiSTer\_db

A MiSTer DB for installing the [MicroBee core](https://github.com/diegov-au/MicroBee_MiSTer) on your MiSTer.

## Prerequisites

* An Internet connected MiSTer

## Setup

1. Add the following to `/media/fat/downloader.ini`.

```ini
[davewongillies/MicroBee_MiSTer_db]
db_url = https://raw.githubusercontent.com/davewongillies/MicroBee_MiSTer_db/db/db.json.zip
```

2. Run `update` or `update_all` from the Scripts menu.
